# Python User Configuration Manager

This is my second independent Python project. It is a terminal-based application that allows a user to manage their configuration settings (like theme and language).

## Features
- **Add Setting:** Adds a new key-value pair. Prevents duplicates and converts all inputs to lowercase.
- **Update Setting:** Updates an existing setting. Throws a custom error if the setting doesn't exist.
- **Delete Setting:** Removes a setting from the dictionary.
- **View Settings:** Displays all current settings with capitalized keys in a clean format.

## Built With
- Python 3
